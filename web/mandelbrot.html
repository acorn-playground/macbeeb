The Distributed Mandelbrot on Econet

BBC Micros draw the Mandelbrot set between them, each tile worked out by its own 6502 and sent back over Econet, with a Level 2 file server keeping the programs. MacBeeb's Network Studio demo, in a browser: every machine here is MacBeeb's emulation, compiled to WebAssembly, all on one network. A single BBC Micro

Loading…

  4. on the Guide: it hands out the tiles, and draws them as they come back. A key on the Guide ends it.
