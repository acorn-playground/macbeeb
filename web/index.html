ROMs

The BBCs start with the ROMs MacBeeb has (Acorn's). To use others, choose them here: they stay in this browser and are never uploaded.

Click a screen to type on that BBC's keyboard. F12 is Break, End is COPY.

No gamepads: connect one and press a button to use it as the BBC's joystick.

Econet

With Econet on, every BBC here gets an Econet module (and its network filing system: DNFS on a Model B, ANFS on a Master) and they share one network, run in step as MacBeeb runs them.

A file server is a BBC running file server software from a disc. "Add a file server" adds one with Acorn's Level 1 file server in its drive: start it there with CH."FS" and answer its questions (the stations that may log on, and their directories).

Internet Econet

Join a room on an Internet Econet service, and the stations here can talk to those of other people, in MacBeeb or in a browser.
